# Space Shooter

A 2D space shooter game developed with JavaScript and PixiJS as a technical test assignment.

The game features two levels with different enemy behaviors, shooting mechanics, and limited resources.

## Play Online

**[Live Demo](https://vladyslavavh.github.io/space-shooter/)**

## Gameplay

The game consists of two levels:

**Level 1 — Asteroids**

Control a spaceship and shoot falling asteroids while managing limited ammunition and time.

**Level 2 — Boss Fight**

Face a moving boss that shoots at the player while asteroids continue to fall.

Each level has:
- A 60-second time limit
- A maximum of 10 player shots

## Controls

| Key | Action |
|---|---|
| Arrow keys | Move the spaceship |
| Space | Shoot |

## Tech Stack

- JavaScript (ES6+)
- PixiJS
- Webpack
- HTML5 / CSS3

## Getting Started

Clone the repository:

```bash
git clone https://github.com/VladyslavaVH/space-shooter.git
cd space-shooter
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Create a production build:

```bash
npm run build
```

## Project Background

Originally created as a technical test assignment, Space Shooter demonstrates fundamental 2D game development concepts using PixiJS, including sprite rendering, player controls, shooting mechanics, enemy behavior, and level management.
